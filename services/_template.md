# Service Entry Template

Every service in this dictionary follows this exact template. Do not deviate — consistency is what makes the dictionary usable.

---

### Service Name (official AWS or vendor name)

| Field | Description |
|---|---|
| **Category** | Networking / Security / Compute / Data / Monitoring / External |
| **Service overview** | What the service is and what it does, described professionally |
| **Purpose in DGBank** | The business, security, or operational reason DGBank uses it |
| **Position in architecture** | The layer it operates in and the request journeys it participates in (reference `docs/03-request-journeys.md`) |
